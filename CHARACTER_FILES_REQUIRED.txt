REALISTIC CHARACTER MODEL FILES

To show the real uploaded student models, place these two files in the same project root folder as game.html:
- char_boy.glb
- char_girl.glb

The current ZIP supplied for this repair did not contain either GLB file, so this repaired ZIP cannot include or display those actual models until the files are added.

The game now waits for its GLB loading attempt to finish instead of starting after a fixed 30-second race. If the files are missing or fail to load, check the GLB status in the game's Settings panel and the browser console.

Classroom desks, chairs, tables and shelves are excluded from static mesh merging so their individual meshes remain in the scene. Other eligible static meshes remain optimized.
